## My First GUI

A simple and interactive Python GUI application built using Tkinter, with image processing capabilities powered by OpenCV and Pillow.

## Features

- User-friendly graphical interface using Tkinter.
- Image processing using OpenCV.
- Image loading and handling using Pillow.
- Simple and interactive design.

## Built With

- Python
- Tkinter
- OpenCV (`cv2`)
- Pillow (`PIL`)


## Getting Started

### Prerequisites

- Python 3 installed on your system.

### Installation

1. Clone this repository:

```bash
git clone https://github.com/adyaa2102-hue/my_first_gui.git
```

2. Navigate to the project folder:

```bash
cd my_first_gui
```

3. Install the dependencies:

```bash
pip install opencv-python Pillow
```

4. Run the application:

```bash
python script.py
```

## Download

Download the packaged macOS application from the [GitHub Releases](https://github.com/adyaa2102-hue/my_first_gui/releases) page.
