# my_first_gui
# Python Meme Login Portal

A simple GUI-based login portal built using Python that displays a meme after the user logs in. This is my first GUI project, created to explore Python GUI development and make a basic login experience a little more fun.

## Features

- Simple and beginner-friendly graphical user interface
- Basic login portal
- Displays a meme after login
- Built using Python
- Created as a first GUI development project

## Technologies Used

- Python (Core programming language)
- Tkinter

## Getting Started

### Prerequisites

- Python 3 installed on your system

### Installation

1. Clone this repository:

   git clone https://github.com/adyaa2102-hue/my_first_gui.git
   

2. Navigate to the project folder:


   cd my_first_gu
  

3. Run the Python file:


   python script.py

## How It Works

1. Launch the application.
2. Enter the login details.
3. Log in to the portal.
4. View the meme displayed by the application.

## What I Learned

- Basics of building a GUI using Python
- Handling user input
- Implementing a simple login flow
- Displaying images through a graphical interface


 ## Demo Limitations

The original GUI was built using Python's Tkinter, which doesn't run directly in web browsers. Therefore, I couldn't deploy it as a live interactive demo.

The source code is available in this repository to explore and run locally. As my first Python GUI project, I'm continuing to learn about application development and deployment.
